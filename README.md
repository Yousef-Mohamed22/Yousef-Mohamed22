### 🏁 [dnsrace](https://github.com/Yousef-Mohamed22/dnsrace)
*High-performance, native cross-platform DNS resolver benchmark utility.*

[![Rust](https://img.shields.io/badge/Language-Rust-orange?style=flat-square&logo=rust)](https://github.com/Yousef-Mohamed22/dnsrace)
[![Platform](https://img.shields.io/badge/Platform-Linux%20%7C%20Windows%20%7C%20macOS-blue?style=flat-square)](#)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](https://github.com/Yousef-Mohamed22/dnsrace/blob/main/LICENSE)

A zero-telemetry desktop application designed to measure real resolver lookup latency, perform automated DNSSEC validation, detect NXDOMAIN hijacking, and apply optimal system configurations across platforms.

### 🛠️ Core Engineering Focus

- 🏎️ **Native Desktop Development:** Engineering reliable, memory-safe desktop applications and tools using modern Rust.
- ⚙️ **System Performance & Optimization:** Configuring kernel parameters, hardware frequency envelopes, power governors, and display stack configurations on Arch-based Linux platforms.
- 🎮 **Graphics Translation & Runtime Profiling:** Evaluating, testing, and debugging translation layers (DXVK, WineD3D, D7VK, DxWrapper, Proton) for Linux software compatibility.
- 🌐 **Network Infrastructure & Security:** Analyzing DNS protocol behaviors (UDP, TCP, DoT, DoH), resolver latencies, and secure network routing.
